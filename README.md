# TCAV
Quantitative Testing with Concept Activation Vectors in PyTorch

> **Status: archived research code.** A PyTorch reimplementation of TCAV (Kim et al., ICML 2018),
> last updated in 2019 and unmaintained since. There is no packaging, no pinned dependency set and no
> usage documentation beyond the notebook in this repository — treat it as a reference
> implementation to read, not a library to install. Released under Apache-2.0, matching the
> upstream [tensorflow/tcav](https://github.com/tensorflow/tcav).
>
> **Current work.** This is an old reimplementation, not a research line of mine. I work on
> embodied AI — world models and VLA policies for robots and virtual worlds — with
> [corl-team](https://github.com/corl-team). Recent code:
> [NE-Dreamer](https://github.com/corl-team/nedreamer),
> [Qantara](https://github.com/corl-team/qantara),
> [VL-DAC](https://github.com/corl-team/VL-DAC).
> More at [rakhimovv.github.io](https://rakhimovv.github.io).
